# Structured Programming Lab (C Language)

This repository contains C programming solutions for **Lab Report 1** using conditional logic (`if-else if`).

## Problems Covered

1. **Character Type Checker:** Identifies whether an input character is an uppercase letter, lowercase letter, digit, or special symbol using ASCII values.
2. **Day of the Week:** Prints the corresponding day name for numbers `1` to `7` and handles invalid inputs.
3. **Days in a Month & Leap Year:** Displays the number of days in a given month (`1-12`) and checks for a leap year if February (`2`) is entered.
4. **Electricity Bill Calculator:** Calculates total electricity charges based on slab-wise unit rates.
5. **Triangle Validity Checker:** Checks whether a triangle can be formed from three given angles.




   ---

## Conditional Logic Problems (`problem 1.c` - `problem 7.c`)

1. **Number Sign Checker (Positive, Negative, or Zero):** Determines whether an entered integer is positive, negative, or zero.
2. **Even or Odd Checker:** Checks if a given integer is even or odd using the modulus (`%`) operator.
3. **Equality Checker:** Compares two input integers and prints whether they are equal or not.
4. **Leap Year Validator:** Checks if a given year is a leap year based on divisibility by `400`, `4`, and `100`.
5. **Multiplier & Maximum Finder:** Checks if one number is a multiple of another and finds the largest number among three integers (`a`, `b`, and `c`).
6. **Age & Ticket Categorizer (`nested-if`):** Verifies if a person's age is above `10` to issue a ticket, then categorizes them as a `Child` (`11–18`) or an `Adult` (`>18`).
7. **Height Categorizer:** Classifies a person's height into categories (`dwarf`, `average man`, `taller gentleman`, or `height is not good`).


## How to Run

1. Open any `.c` file in a C compiler (such as **Code::Blocks** or **GCC**).
2. Compile and run the program (`F9` in Code::Blocks).
3. Enter the required input in the console to view the output.
